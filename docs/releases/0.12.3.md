TUInk 0.12.3 reduces deletion-history overhead and completes the transition to semantic editor commands.

Changes since v0.12.2.

## Fixes and improvements

- Backspace, Delete and selection deletion record local reversible edits instead of copying the whole document into undo history. Undo and redo retain grapheme boundaries, savepoints and exact line-ending slices.
- Editor commands use one semantic routing path across menus, keys and dialogs. Obsolete input adapters and unused UI implementations have been removed after their callers migrated.
- The README introduces the editor's features, and a Russian setup guide covers building, recovery and document storage.

## Downloads

- `tuink-0.12.3.zip`: JVM distribution; requires Java 17 or newer.
- `tuink-0.12.3-linux-x86_64.tar.gz`: Linux x86_64 native distribution for glibc systems.
- `tuink-0.12.3-linux-x86_64-musl.tar.gz`: Linux x86_64 static musl distribution.
- `tuink_0.12.3_amd64.deb`: Debian package for Linux x86_64.
- `SHA256SUMS`: distribution checksums.

## For builders

Use JDK 17 for `JAVA_HOME`, JVM compilation and tests, with the checked-in Gradle 8.14.5 wrapper. The JVM vendor is not pinned. Native and release builds separately require GraalVM Community 25.2.4 / Java 25 selected through `GRAALVM_HOME`; Gradle itself continues to run on JDK 17.

The render benchmark harness requires Python 3.10+ and a POSIX environment. Settings remain at format 1 and recovery snapshots at format 5. Java toolkit and editor APIs remain internal and incubating.
