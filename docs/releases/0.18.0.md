TUInk 0.18.0 adds terminal Markdown preview with linked Source and Preview tabs,
Unicode formulas and Mermaid diagrams, system clipboard integration and a
shared Monochrome palette. It also improves keyboard, settings and recovery
workflows.

Changes since [v0.17.0](0.17.0.md).

## Markdown preview

- Markdown supports adjacent linked Source and Preview tabs, with Source
  on the left. `Ctrl+P` creates or selects Preview; from Preview it selects or
  reopens Source at the preview caret, preserving Unicode insertion boundaries.
  Normal tab navigation and `Ctrl+W` include both tabs. Esc leaves Find or
  cancels a dialog while keeping Preview selected.
- Preview admission uses the shared filename registry: `.md`, `.markdown`,
  `.mdown`, `.mkd` and `.mkdn`, ignoring case. An unnamed draft needs a Markdown
  filename first. Two Settings options control future opens: **Open both
  Markdown tabs** and **Open Markdown in Preview** both default to off. Preview-only opening releases the clean editor; returning to Source
  reads the linked file using the decoder of its last load or confirmed save.
- Source closure uses normal Save / Discard / Cancel. Preview may retain its
  accepted raw snapshot after Source and its Undo history are released. This
  adds no hidden editor, dirty document or duplicate recovery draft; closing
  the snapshot does not repeat a discarded source's save question. Snapshot-only
  tabs are session-only and are not restored by startup recovery.
- Save and Save As in Preview use the latest live buffer or the retained raw
  snapshot through the same version, authorization and receipt protocol.
  Encoding, BOM, mixed line endings and final separators are preserved.
  Confirmed Save As updates the pair's name and reopen target without opening
  an editor. A save while Preview is hidden also updates the reopen decoder;
  undoing the output format keeps the decoder of the confirmed disk bytes.
  Unavailable current resources report ordinary errors; explicit
  Save As can export the snapshot. A publishing snapshot save keeps its tab
  open until an outcome is known; an unconfirmed outcome keeps the application
  and raw snapshot available for verification.
- Parse, reopen and save publication check presentation identity, source and
  binding generation. Late results do not change another tab or revive a
  closed editor. Hidden previews release heavy layouts and cancel their
  subscriptions while retaining raw source and navigation within window budgets.
- Preview supports framed GFM tables, an acyclic Mermaid flowchart subset,
  sequence diagrams, and two-dimensional TeX formulas using terminal Unicode
  cells. Unsupported diagram syntax and mathematical commands retain their
  source; image protocols are not required.
- Preview has independent selection, copying and text search through the shared
  bounded matcher. **Edit** commands copy a block's source or a table as TSV;
  **View → MD Source** returns to Source at the preview position, including
  when an empty or unfinished preview has no text mapping.
- **MD copy as displayed**, off by default, copies prepared formulas, diagrams,
  table frames and quote markers with the same visible control-character and
  grapheme replacements as the screen. Normal paragraph wrapping adds no
  clipboard line breaks. With the option off, Copy retains semantic text.
- Preview code blocks use the Source language aliases and syntax palette on
  a full-width dark-gray background. Quote markers have their own style.
  **MD code syntax**, off by default, independently enables language highlighting
  inside Markdown Source code blocks; disabled blocks retain uniform styling.
- Scrolling keeps the visual cursor within the visible content. Arrow keys
  navigate rendered rows inside formulas and diagrams; Page Up and Page Down
  retain a one-line overlap. Returning to Preview refreshes its source and
  restores navigation anchors; obsolete background results are discarded.

## Clipboard and appearance

- Copy, Cut and Paste share a system clipboard across tabs and editable fields.
  Linux uses available Wayland or local X11 helpers; macOS uses `pbcopy` and
  `pbpaste`. Transfers run on a bounded worker. SSH and headless sessions retain
  the shared application clipboard and terminal paste. Failed transfers report
  a warning and retain the internal clipboard.
- **Right-click: copy/paste**, off by default, copies an active selection and
  clears it, or pastes at the current caret in editable content. Preview remains
  read-only; its Find field supports the same clipboard actions as other fields.
  Deferred paste checks its original document or field before applying a result.
- **Monochrome** provides neutral palettes for Source, Preview, code, brackets
  and window controls. Syntax highlighting, rainbow brackets and Markdown code
  syntax remain configurable. Indexed/RGB terminals use gray gradations;
  ANSI-16 terminals use neutral fallbacks.
- The six top-level menus group related commands. Availability checks are shared
  by menus and shortcuts and explain unavailable actions in the status line.

## Keyboard, files, settings and recovery

- Quit and close confirmations can be completed from the keyboard. `Ctrl+S`
  saves, Tab and Shift+Tab cycle through action buttons, and Enter activates
  the focused action, initially Cancel. Narrow prompts wrap the full question
  and actions instead of hiding the filename.
- `Ctrl+W` closes the current tab. Save As remains available through `Ctrl+K`
  or `Ctrl+Shift+S`; menu hints follow the active bindings. Search controls
  wrap in narrow terminals, keeping options and actions accessible.
- `N` discards changes in quit and close-tab confirmations; Esc cancels.
  A repeated `Ctrl+Q` also discards in the quit confirmation. Labels and
  keyboard handling share the same context-specific shortcut policy.
- The file picker accepts editable paths through `Ctrl+L`; Enter opens a file
  or navigates to a directory. `Alt+.` toggles hidden files without ambiguity
  with terminals that encode Backspace as `Ctrl+H`.
- Postponed recovery can be reopened without blocking normal input. Pending
  snapshot publication is also respected when quitting from another tab;
  an uncertain result keeps the window and snapshot open.
- Recovery offers **Y=Restore**, **D=Delete**, **N/Esc=Later** and **Ctrl+Q=Quit**.
  Later is initially focused. Delete removes only the offered recovery copies;
  Later and Quit preserve them, including when current documents are saved
  or discarded during normal exit.
- Readable unsupported settings offer **Fix / Delete / Later**, initially
  focused on Later. Explicit Fix retains valid current-format fields and
  supplies defaults for invalid fields; an unsupported whole format or malformed
  properties file resets to defaults. Delete removes the selected profile entry.
  Both actions reject externally changed files. Later keeps the file and makes
  preferences temporary; queued recovery is offered after the settings choice.
  Settings load and persistence failures remain visible inside the editor.

## For builders

- Portable Markdown, Math and Mermaid models/providers remain independent
  of the terminal UI and editor engine. See the
  [Markdown preview guide](../markdown-preview.md) for controls, syntax and
  resource limits.
- Portable frozen-source contracts and save subjects share the document I/O
  coordinator without requiring an editing session. External Java 17 and
  D8/R8 probes check reusable boundaries; Android storage, lifecycle and UI
  support remain separate work.
  Backend save-operation interfaces now belong to `editor.storage`; consumers
  compiled against the previous nested backend interfaces must be recompiled.
- Source and Preview share prepared rows, Unicode geometry, viewport interaction,
  modal placement, window painting and recipient checks for asynchronous work.
  Application close decisions live in the portable session layer. TUIframe
  `ScreenPresenter.PresentResult` adds `outputNanos`; consumers of its previous
  record constructor must be recompiled.

The JVM application requires Java 25. Portable editor and Markdown modules
retain their Java 17 baseline. Native builds use the pinned Oracle GraalVM
25.0.4+7.1 SDK and the portable `compatibility` CPU baseline. Settings now use
format 2. Format 1 and unsupported profiles are preserved until an explicit
Fix or Delete choice; no automatic migration is performed. The CLI and saved
theme name is `monochrome`, replacing `light` without a legacy alias. Recovery
readers accept exact formats 5 through 8 and writers use format 8.
