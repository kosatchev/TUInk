# TUInk 0.20.0

Changes since [v0.19.0](0.19.0.md).

- Run architecture test classes in separate JVMs so imported class graphs are released between suites.

- Share one unsigned JGit runtime artifact between independent adapters instead of preparing duplicate class copies.

- Extract bounded Unicode text matching into the reusable Java 17 editor-search-text library. Preserve existing search semantics and carry the new JAR through external and memory-limited consumers.

- Add a portable cancellable project-search service and JVM streaming sources with bounded inventory/results, ignore and hidden-file policies, explicit encodings and versioned matches.

- Add reusable dropdowns and check buttons, semantic inversion through the renderer, focus accents and readable placeholders that retain the input surface. Disabled inputs are muted and skipped by focus navigation.

- Add reusable collapsible tool palettes and a dock with sizing, menu placement, per-palette hints and keyboard reordering. Share a stationary 500 ms drag gesture with the file explorer; early motion cancels until release.

- Integrate Strict, Wildcard and Regex across Source, Preview and project search. Add the Files/Search palette dock, retained layout and independent hints, responsive controls, version-checked navigation, explicit Add gitignore/Add hidden flags and example-only filters.

- Keep the active content selection caret light in both selection directions, including wide graphemes, Preview and monochrome, without recoloring control cursors.

- Expose confirmed overwrites through the editor API/session/storage boundary. A typed external conflict leaves the draft intact; explicit approval replaces only the freshly inspected disk version and retains alias, version and publication race checks.

- Replace external-change buttons and Keep with File → Update from disk (F1 → U) and Save (Ctrl+S) instructions. Require explicit loss confirmation for overwrites; keep warnings through cancel and rename. Auto-reload clean Source/frozen Preview by default, preserve cursor/scroll and protect retained local edits. Persist the preference.

- Add an atomic move-selection editor command. Preserve exact original line separators, Unicode ranges, clipboard contents and selection; reject stale/self drops and retain one Undo/Redo step.

- Add the persisted Drag selected text preference, off by default. Use the shared stationary 500 ms hold, a separate insertion cursor and edge scrolling; early motion remains ordinary selection and release moves the range in one Undo step.

- Keep previous project-search results outdated when a changed query is stopped before it starts, so navigation cannot validate old ranges with the new expression.

- Complete PGO dependency locks and training settings for the current search and editing options.

- Refresh terminal regressions for confirmed external overwrites and the shared search-mode dropdown.

- Let Gradle clean remove PTY and native ACL fixtures with raw Unix filenames while preserving symlink containment.

- Unify Files and Search selection colors: themed focused rows, black on light gray without focus, and gray on gray only when disabled. Hide the Files list cursor so disclosure marks retain the same colors as their labels.

- Keep Search enabled and retain its selected control beneath menus and dialogs, matching Files; temporarily transferring input focus must not gray out the palette.

- Apply parent exclusions before entering a project-search subfolder scope or an ignored working root. Child `.gitignore` negations cannot bypass the parent or substitute the disk copy for an excluded open buffer.

- Resolve project-search repository ignore rules through symlinked working roots while retaining logical result paths and live-buffer priority.
